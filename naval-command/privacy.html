Confidentialité · NAVAL COMMAND

Application : NAVAL COMMAND
Éditeur : Alba Technologies Innovation Lab
Plateforme : Android
Contact : contact.alba.play@gmail.com
Dernière mise à jour : 13 août 2026

Multijoueur en ligne

Les salons publics et privés utilisent Firebase Authentication anonyme et Firebase Realtime Database pour identifier techniquement les joueurs, gérer la présence et synchroniser les parties.

Les données de jeu en ligne peuvent notamment comprendre l’identifiant anonyme, le code du salon, l’état de préparation, la flotte, les tirs, le tour en cours et le résultat de la partie.

Progression locale

La progression, les missions, les skins, le Hangar, les badges, les mines et certains réglages peuvent être enregistrés localement sur l’appareil.

Google Play Games

NAVAL COMMAND peut utiliser Google Play Games pour les fonctions associées au compte Google du joueur.

Publicité

NAVAL COMMAND peut afficher des publicités Google AdMob, notamment des formats intégrés au jeu et des publicités récompensées lorsque cette fonction est proposée.

Suppression

Les données locales peuvent être supprimées depuis les paramètres Android ou par désinstallation. Pour les données encore présentes en ligne, consultez la page de suppression des données.

Contact

Pour toute question : contact.alba.play@gmail.com.

Le multijoueur utilise des services en ligne. Les modes Contre l’IA et Missions restent distincts des salons publics et privés.
