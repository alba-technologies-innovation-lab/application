Données locales

ÉTERNALIS est un jeu solo local. Les données de jeu locales peuvent être supprimées depuis les paramètres Android en effaçant les données ou le stockage de l’application.

La désinstallation supprime également les données locales associées selon le fonctionnement normal d’Android.

Compte en ligne

ÉTERNALIS ne nécessite pas de compte joueur en ligne ni de salon multijoueur pour jouer.
