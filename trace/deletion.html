Suppression des données locales

Les données stockées localement par TRACE peuvent être supprimées depuis les paramètres Android en effaçant les données de l’application, ou en désinstallant l’application.

Données synchronisées en ligne

TRACE utilise Firebase Authentication en mode anonyme et Firebase Realtime Database pour permettre le fonctionnement des salons et des parties multijoueurs.

La suppression des données locales de l’application ne garantit pas la suppression immédiate de toutes les données déjà synchronisées à distance.

Demander la suppression de données encore présentes

Si vous souhaitez demander la suppression de données encore présentes côté service, contactez Alba Technologies Innovation Lab à contact.alba.play@gmail.com.

Pour permettre de retrouver les données concernées, indiquez si possible le pseudo utilisé, le code du salon et toute information utile permettant d’identifier la partie ou le salon concerné.

Authentification anonyme

TRACE ne demande pas de compte utilisateur classique ni de mot de passe personnel. L’identifiant Firebase anonyme peut changer après une désinstallation, une réinstallation ou une réinitialisation des données de l’application.

En savoir plus

Pour connaître les données utilisées par TRACE et leur finalité, consultez la politique de confidentialité de TRACE – Fracture du Flux.
